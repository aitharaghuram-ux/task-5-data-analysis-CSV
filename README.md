Task 5 Data Analysis on CSV Files

In this task, I worked on a sales dataset using Python. The main purpose of this task was to understand how data can be loaded, analyzed and visualized using Python.

I used Google Colab to write and run my Python code. I used the Pandas library because it helps in working with CSV files and makes it easier to analyze data in the form of tables. I also used Matplotlib to create charts from the analyzed data.

First, I loaded the CSV files using the read_csv() function in Pandas. I used functions like head(), shape and columns to understand the data and see what information was available.

After that, I calculated the total sales using sum(). I used groupby() to group the data based on different categories and then used sum() to find the total sales, profit and quantity for each category.

I also analyzed sales by sub-category and state. I used bar charts to make the results easier to understand.

The main functions I used were read_csv(), head(), shape, columns, groupby(), sum() and plot(). I learned how these functions can be used together to find useful information from a dataset.

From this task, I learned the basics of Pandas, how to work with CSV files, how to group and calculate data, and how to create simple charts. I also understood that data analysis can help us find useful information such as which category has higher sales and profit.
